## Keymaps <br>

### origin neovim operations <br>
ctrl + s    -> :w --save <br>
q           -> :q! --quit <br>
sd          -> ctrl + w + v --new horizontal window <br>
sw          -> ctrl + w + s --new vertical window <br>
e           -> :nohl --no highlight <br>

### plugins operations <br>
space       -> :NvimTreeToggle --toggle nvim tree <br>  
ctrl + down -> mc.lineAddCursor(1) --multicursor add <br>
